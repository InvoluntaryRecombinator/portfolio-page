# Portfolio Content Handoff Worksheet

Use this document to prepare the final content for the portfolio. Every editable
item has a stable number so it can be mapped back into the website without
guessing.

## How to edit this document

For each item, replace the text inside the **Replacement** block.

- Write `[KEEP]` to retain the current text.
- Write `[REMOVE]` to remove the item entirely.
- Write `[TBD]` when you are not ready to decide.
- Keep the item numbers and headings unchanged.
- Normal capitalization is fine. The website can visually transform text to
  uppercase where the design requires it.
- Project summaries should ideally be one or two short sentences.
- Project overviews can be one to three short paragraphs.
- URLs should include the complete `https://` address.

# Return checklist

Before returning the worksheet, check whether you supplied:

- Your name, role, location choice, and availability
- Email, LinkedIn, and résumé destination
- Browser title and site description
- Final hero statement and short introduction
- Final project count and order
- A title, year choice, summary, and overview for every project
- Asset paths or clear `TBD` markers for every project
- Any live-project or repository links
- Any labels or sections you want removed

You do not need to solve every field at once. Items marked `[TBD]` can remain as
placeholders during the next design pass.
